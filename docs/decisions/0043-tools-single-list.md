# 0043 - Tools uses one list and scoped action menus

**Date:** 2026-11-01
**Status:** Accepted by the owner

Replace the three Tools screens and machine-column cursor with one searchable
list of skills and MCP servers. Enter opens applicable actions. Status uses
words; attention rows come first. Project, node and machine filter terms share
the action scope. Graph's t opens the selected node's Tools filter.

Keep the existing plan, apply, import, backup and undo services. Add owner-gated
MCP operator wrappers, a bounded folder import, stored-skill reading, and an
explicit copy-choice operation. A copy choice imports the selected version
before the host backs up the other exact observed native user copies. Hash,
source and owner checks stay on the daemon and gateway.

Each modal replaces the Tools content with one clean box. Its key bar follows
the mode. The CTO box layout is unchanged by this decision.
