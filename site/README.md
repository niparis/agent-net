# site

Everything published at https://niparis.github.io/agent-net/ besides the installer.

| Path | What |
|---|---|
| `pages/` | The published files, served as they are. `pages/architecture/index.html` is built; the rest is copied. |
| `pages/architecture/gateway-network/` | The network of gateways design (decision 0178) and its three diagrams. |
| `build.sh` | Rebuilds `pages/architecture/index.html`. Needs `python3` only. |
| `build/` | The build steps, run in the order `build.sh` lists them. |
| `build/data/base.json` | A snapshot of the data model: tables, entities, lifecycles, journeys, taken from the code and the live gateway on 2026-11-22. It is not regenerated by the build. |
| `build/data/template.html` | The page shell the steps fill in. |
| `build/data/feature_details.json` | The text shown when a feature row is opened. |
| `build/data/conductor-tab.html` | The Conductor architecture tab, written by a friend of the owner, kept as published. |

## Change the page

1. Edit a source. The guide reads `README.md`, `docs/quickstart.md` and `docs/principles.md`, so most text changes are edits to those files. Tab layout and the other text live in the steps under `build/`.
2. Run `site/build.sh`.
3. Commit the sources and `pages/architecture/index.html` together.

The Pages workflow deploys on every push to `main` that changes `site/`. Each run rebuilds the whole site with the installer of the latest release.
